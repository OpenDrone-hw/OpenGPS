OpenDrone 6-layer board

Line-standard board setup

Starting point for a new OpenDrone board. It carries no design: what it carries is the setup every board in the line shares, so a new board does not start by guessing at constraints.

What it sets

  • 6 copper layers
  • Clearance 0.09 mm, minimum track width 0.09 mm
  • Via 0.35 mm diameter on a 0.20 mm drill, annular ring 0.075 mm
  • Hole to hole 0.20 mm, copper to board edge 0.20 mm
  • Track width presets 0.15 / 0.25 / 0.40 / 0.80 mm
  • One via size, so a board does not accumulate four of them

These are the JLCPCB-buildable numbers the line settled on. A board that needs something tighter or heavier expresses it as a custom rule in its .kicad_dru, not by moving the board minimum. The ESC boards are the worked example: 2 oz outer copper needs 0.16 mm on the outer layers, and that is a layer-scoped rule, so the inner layers keep the standard.

Existing boards

This template is for new projects. To bring an existing board onto the same setup, open it and use Board Setup > Import Settings from Another Board, pointed at OpenDrone-6L.kicad_pcb. That imports the layer stackup, the constraints, the track and via presets, the custom rules and the violation severities in one step.

Not set here

Net classes. Every board in the line currently has one class, Default, and standardising them is open work rather than something this template should decide.
